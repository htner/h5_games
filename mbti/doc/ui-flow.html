推送事件驱动

服务端通过 room_push → Flutter WS → H5 onDartEvent 推送游戏状态

导航 game_started → Lobby
导航 guessing_started → Guessing
状态 target_locked 显示锁定提示
状态 guess_count 更新人数
导航 reveal_distribution → Reveal
状态 reveal_answer 正确答案 + 结果
导航 profile_ready → Profile
导航 settlement → Settlement
